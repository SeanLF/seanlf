# Hi, I'm Sean 👋

I build products and look after them: working out what to build, building it,
running it, and getting paged when it breaks. I like owning the whole thing.

I grew up across six countries and now work remotely from Europe.
[seanfloyd.dev](https://seanfloyd.dev) has my CV and what I'm looking for.

## Things I've built

**[Steer](https://steer.seanfloyd.dev)**: turns a game controller into a full
Mac input device, for when a mouse is tiring or painful. Swift, built alone,
code to website.

**[still_active](https://github.com/SeanLF/still_active)**: tells you which of
your dependencies nobody maintains any more, before the CVE does.

**[news-digest](https://github.com/SeanLF/news-digest)**: a daily news briefing
that nobody edits. Unattended since January 2026;
[cost and every failure are public](https://news-digest.seanfloyd.dev/stats).

**[ccpool](https://github.com/SeanLF/ccpool)**: dollars left in your Claude
subscription, and whether you're burning it too fast.

**Dispatch** (private): back-office workflows for regulated businesses, where
nothing reaches a client on the model's word alone. Not in production yet.
